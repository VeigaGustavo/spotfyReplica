## Objetivo

O principal objetivo deste projeto é aprimorar habilidades em desenvolvimento front-end, praticando a construção de interfaces responsivas e interativas.

Estou aprendendo com a **Hashtag Programação** e aplicando os conhecimentos adquiridos neste projeto.

## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/spotifyReplica.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd spotifyReplica
   ```
3. Instale as dependências e execute o projeto:
   ```bash
   npm install
   npm run dev
   ```
   Caso contrário, basta abrir o arquivo `index.html` no navegador.
